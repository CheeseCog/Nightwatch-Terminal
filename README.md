## 📖 About

Nightwatch Terminal is a companion vault built for **Welcome to the Game 3** using Obsidian.

It helps you organise investigations, track discovered websites, manage intelligence across multiple runs and reduce repetitive note-taking while keeping the gameplay experience spoiler-friendly.

Built over many months, Nightwatch Terminal aims to feel less like a notebook and more like an investigation terminal.

## 🚀 Quick Start

### Requirements

Install:

- Obsidian
- Minimal Theme

Community Plugins:

- Advanced Multi Column
- Commander
- Homepage
- Iconize
- Meta Bind
- Minimal Theme Settings
- QuickAdd
- Style Settings

---

### Installation

1. Download the latest release.
2. Extract the ZIP.
3. Open the folder as an Obsidian vault.
4. Trust the vault and enable community plugins.
5. Install any missing plugins if prompted.
6. Open the Dashboard.
7. Press **New Run**.
8. Start investigating.
