# 🚀 Getting Started

Never used Obsidian before?

No problem! Nightwatch Terminal is an interactive companion built using **Obsidian**, a free note-taking application.

You don't need any previous experience—just follow these steps.

---

## Step 1 - Install Obsidian

Download Obsidian (it's completely free):

👉 https://obsidian.md/download

Install it like any normal application.

---

## Step 2 - Download Nightwatch Terminal

Go to the **Releases** section of this GitHub repository.

Download the latest version and extract the ZIP file.

---

## Step 3 - Open the Vault

Open Obsidian.

Click:

**Open folder as vault**

Select the extracted **Nightwatch Terminal** folder.

---

## Step 4 - Trust the Vault

The first time you open it, Obsidian will ask:

> **Do you trust the author of this vault?**

Click:

**✅ Trust author and enable plugins**

Nightwatch Terminal relies on community plugins for its interactive buttons and automation.

---

## Step 5 - Install Missing Plugins

If prompted, install the following community plugins:

- Advanced Multi Column
- Commander
- Homepage
- Iconize
- Meta Bind
- Minimal Theme Settings
- QuickAdd
- Style Settings

---

## Step 6 - Install the Minimal Theme

Open:

Settings → Appearance → Community Themes

Install:

**Minimal**

Then activate it.

---

## Step 7 - Start Investigating

That's it!

When the Dashboard opens:

1. Press **🟢 New Run**
2. Tick discovered websites.
3. Press **🚀 Update Investigation**
4. Investigate.
5. Press **✅ Finish Run**

Happy investigating!
