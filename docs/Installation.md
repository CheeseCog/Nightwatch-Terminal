# 🚀 Installation

Follow these steps to get Nightwatch Terminal up and running.

---

## 1. Install Obsidian

Download the latest version of Obsidian from the official website:

🔗 https://obsidian.md/download

Install and launch Obsidian.

---

## 2. Download Nightwatch Terminal

Download the latest release from the **Releases** page on GitHub.

Extract the ZIP file somewhere on your computer.

---

## 3. Open the Vault

In Obsidian:

1. Click **Open folder as vault**
2. Select the extracted **Nightwatch Terminal** folder
3. Click **Open**

---

## 4. Trust the Vault

When opening the vault for the first time, you'll see:

> **Do you trust the author of this vault?**

Click:

**✅ Trust author and enable plugins**

This enables the automations used throughout the vault.

---

## 5. Install Community Plugins

If Obsidian reports missing community plugins, install the following:

| Plugin | Required |
|---------|:-------:|
| Advanced Multi Column | ✅ |
| Commander | ✅ |
| Homepage | ✅ |
| Iconize | ✅ |
| Meta Bind | ✅ |
| Minimal Theme Settings | ✅ |
| QuickAdd | ✅ |
| Style Settings | ✅ |

After installing them, reload the vault if prompted.

---

## 6. Install the Minimal Theme

Open:

**Settings → Appearance → Themes**

Browse Community Themes and install:

**Minimal**

Then enable it.

---

## 7. Start Your First Investigation

From the Dashboard:

1. Press **🟢 New Run**
2. Open **Website Checklist**
3. Tick every website you discover
4. Press **🚀 Update Investigation**
5. Investigate the generated websites
6. Press **✅ Finish Run** when you're done

That's it!

Happy investigating. ❤️
